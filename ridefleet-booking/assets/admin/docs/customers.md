# admin-customers.css — Customers Page

Loaded on: `ridefleet-customers`

## Classes

- `.rfb-profile-card` — customer summary card with teal gradient background
- `.rfb-profile-card strong` — large customer name
- `.rfb-profile-card span` — muted detail text (email, phone, stats)

The customers page also uses `.rfb-stat-grid` + `.rfb-stat` from global for the top KPI row,
and `.rfb-table-panel` + `.rfb-bookings-table` from bookings for the booking history table.
