# admin-operational.css — Operational Page

Loaded on: `ridefleet-operational`

## Classes

- `.rfb-operational-grid` — auto-fit grid of tool cards (min 240px per column)
- `.rfb-operational-card` — individual tool card (border, shadow, hover lift, teal accent on hover)
- `.rfb-operational-card .dashicons` — icon chip with teal background
- `.rfb-operational-card strong` — tool name
- `.rfb-operational-card small` — tool description text
- `.rfb-hub-tools` — 3-column variant of `.rfb-field-grid` used within operational sections
