# admin-post-types.css — Post Type Edit Screens

Loaded on: `rfb_vehicle`, `rfb_driver`, `rfb_extra`, `rfb_route` post type screens

## Meta Box Components
- `.rfb-meta-box` — grid container for meta fields inside a postbox
- `.rfb-meta-box-wide` — 2-column variant for wider meta boxes
- `.rfb-meta-box-wide .rfb-meta-field:last-child` — last field spans full width
- `.rfb-meta-field` — individual field wrapper (bordered, rounded, light background)
- `.rfb-meta-field label` — field label
- `.rfb-meta-field input.widefat`, `select.widefat` — full-width styled input/select
- `.rfb-meta-field textarea.widefat` — full-width styled textarea

## Post Type List & Edit Screen Polish
- `.post-type-rfb_vehicle .wp-list-table` (and rfb_driver, rfb_extra, rfb_route)
  — bordered rounded list table with shadow
- `.post-type-rfb_vehicle #poststuff .postbox` (and others)
  — rounded, bordered postbox with shadow
- `.post-type-rfb_vehicle #poststuff .postbox-header` (and others)
  — light grey postbox header with bottom border
- `.post-type-rfb_vehicle .rfb-meta-field` (and others)
  — rounded light background for meta fields on these post types
